## 1. 信息表示（第 2 章）

| 公式 | 说明 |
|---|---|
| $`\mathrm{B2U}_w(x) = \sum_{i=0}^{w-1} x_i \cdot 2^i`$ | 无符号编码，范围 $`[0, 2^w-1]`$ |
| $`\mathrm{B2T}_w(x) = -x_{w-1} \cdot 2^{w-1} + \sum_{i=0}^{w-2} x_i \cdot 2^i`$ | 补码编码，范围 $`[-2^{w-1}, 2^{w-1}-1]`$ |
| $`\mathrm{T2U}_w(x) = x + x_{w-1} \cdot 2^w`$ | 补码 → 无符号 |
| $`\mathrm{U2T}_w(u) = u - u_{w-1} \cdot 2^w`$ | 无符号 → 补码 |
| 地址空间 = $`2^w`$ 字节 | 32 位 → 4GB；48 位 → 256TB |
| 指针大小 = $`w/8`$ 字节 | 32 位机 4B，64 位机 8B |
| 十六进制位数 = $`\text{二进制位数} / 4`$ | 4 bit = 1 hex |

**移位**
| 公式 | 说明 |
|---|---|
| $`x \ll k = x \times 2^k`$（$`\bmod 2^w`$） | 左移 |
| $`x \gg k`$（逻辑）$`= x / 2^k`$ 向下取整 | 无符号 |
| $`x \gg k`$（算术）| 符号位填充，向下取整 |

**位技巧**
| 公式 | 说明 |
|---|---|
| $`x \& -x`$ | 取最低位的 1 |
| $`x \& (x-1)`$ | 清除最低位的 1 |
| $`x \oplus y \oplus y = x`$ | 异或自反 |
| $`\lnot x + 1 = -x`$ | 取负 |

## 2. 整数运算（第 2 章）

| 公式 | 说明 |
|---|---|
| 无符号加法 $`s = (x+y) \bmod 2^w`$ | 溢出判定 $`s < x`$ |
| 补码加法 $`s = (x+y) \bmod 2^w`$（有符号解释） | 正+正=负→正溢出；负+负=正→负溢出 |
| 补码取负 $`-x = \lnot x + 1`$ | $`-\mathrm{TMin} = \mathrm{TMin}`$ |
| 无符号乘法 $`(x \cdot y) \bmod 2^w`$ | 低 $`w`$ 位 |
| 补码乘法 | 位级同无符号 |
| 有符号除法（C 向零）$`(x + (1 \ll k) - 1) \gg k`$ | $`x<0`$ 时 |
| $`x * C`$ = 移位 + 加减 | 如 $`x*5 = (x \ll 2)+x`$ |

**溢出判定表**

| 运算 | 结果符号 | 判定 |
|---|---|---|
| 正 + 正 | 负 | 正溢出 |
| 负 + 负 | 正 | 负溢出 |
| 无符号加 | $`<`$ 任一操作数 | 溢出 |

## 3. IEEE 754 浮点（第 2 章）

| 公式 | 说明 |
|---|---|
| $`V = (-1)^s \times M \times 2^E`$ | 浮点值 |
| $`\mathrm{Bias} = 2^{k-1} - 1`$ | $`k`$ = 阶码位数 |
| 单精度：$`\mathrm{Bias} = 127`$，$`1 \mid 8 \mid 23`$ 位 | float |
| 双精度：$`\mathrm{Bias} = 1023`$，$`1 \mid 11 \mid 52`$ 位 | double |
| 规格化 $`M = 1.f`$，$`E = e - \mathrm{Bias}`$ | $`0 < e < 2^k-1`$ |
| 非规格化 $`M = 0.f`$，$`E = 1 - \mathrm{Bias}`$ | $`e = 0`$ |
| 特殊值 $`e`$ = 全1：$`f=0`$ → $`\pm\infty`$；$`f \ne 0`$ → NaN | |
| 最小非规格化正数（单）= $`2^{-149}`$ | `0x00000001` |
| 最小规格化正数（单）= $`2^{-126}`$ | `0x00800000` |
| 最大规格化（单）$`\approx 3.4 \times 10^{38}`$ | `0x7F7FFFFF` |
| 阶码位数 $`k`$，尾数位数 $`n`$，总位 $`1+k+n`$ | |
| 精度（有效位）= $`n + 1`$（含隐含 1） | 单精度 24 位 |

**特殊值位模式**
| 值 | 单精度 hex |
|---|---|
| +0.0 | `0x00000000` |
| -0.0 | `0x80000000` |
| $`+\infty`$ | `0x7F800000` |
| $`-\infty`$ | `0xFF800000` |
| NaN | `0x7FC00000` |

## 4. 机器级/过程调用（第 3 章）

| 公式/规则 | 说明 |
|---|---|
| 寻址 $`\mathrm{Imm}(r_b, r_i, s)`$ → $`\mathrm{Imm} + R[r_b] + R[r_i] \cdot s`$ | $`s \in \{1,2,4,8\}`$ |
| 数组 $`A[i]`$ 地址 = $`x_A + L \cdot i`$ | $`L`$ = sizeof(T) |
| 二维 $`A[i][j]`$ 地址 = $`x_A + L \cdot (C \cdot i + j)`$ | 行优先，$`C`$ 列 |
| 参数寄存器 = `rdi, rsi, rdx, rcx, r8, r9` | 第 7 个入栈 |
| 调用前 `%rsp` $`\equiv 0 \pmod{16}`$ | 16 字节对齐 |
| `pushq` → `%rsp -= 8`；`popq` → `%rsp += 8` | 栈向低地址增长 |
| 返回地址在 `[%rbp + 8]` | 第 7 参数在 `[%rbp+16]` |
| `lea (%rdi,%rdi,2),%rax` → `3×rdi` | 常见算术模式 |

## 5. 结构体对齐（第 3 章）

| 规则 | 说明 |
|---|---|
| 成员偏移 $`\equiv 0 \pmod{\text{成员对齐}}`$ | 对齐 = 自身大小（$`\le 8`$ 时） |
| `sizeof(struct)` $`\equiv 0 \pmod{\text{最大成员对齐}}`$ | 尾部填充 |
| `sizeof(union)` = $`\max(\text{成员大小})`$，再向上取到对齐 | |
| 数组元素间隔 = `sizeof(T)` | |
| 典型大小：char 1, short 2, int 4, long/指针 8, float 4, double 8 | |

## 6. 流水线与处理器（第 4 章）

| 公式 | 说明 |
|---|---|
| 非流水延迟 = $`k \times t`$（$`k`$ 级，每级 $`t`$） | |
| 流水吞吐 = $`1/t`$，加速比 $`\approx k`$ | |
| $`\mathrm{CPI} = 1 + \text{停顿周期数}/\text{指令数}`$ | |
| 理想 $`\mathrm{ILP}`$ 加速 $`\le k`$（流水线深度） | |
| 关键路径限制：$`\mathrm{CPE} \ge \text{延迟}/\text{并行度}`$ | |
| 吞吐量限制：$`\mathrm{CPE} \ge \text{发射时间}/\text{功能单元数}`$ | |
| Y86 $`\mathrm{valP} = \mathrm{PC} + \text{指令长度}`$ | 取指阶段 |
| `call`：$`\mathrm{valE} = -8 + \mathrm{valP}`$，压返回地址 | |

## 7. 程序性能（第 5 章）

| 公式 | 说明 |
|---|---|
| $`\mathrm{CPE} = \text{周期数} / \text{元素个数}`$ | 越小越好 |
| 运行时间 $`\approx \mathrm{CPE} \times n + \text{常数}`$ | $`n`$ 为元素数 |
| **Amdahl** $`S = 1 / ((1-\alpha) + \alpha/k)`$ | $`\alpha`$ 可加速占比，$`k`$ 加速倍数 |
| Amdahl 上界（$`k \to \infty`$）$`S_{\max} = 1/(1-\alpha)`$ | |
| 并行关键路径 $`= \text{最长依赖链长度} \times \text{单元延迟}`$ | |
| 加速比 $`= \text{原时间} / \text{新时间}`$ | |

## 8. 磁盘与 SSD（第 6 章）

**机械磁盘**（⚠️ 高频）

| 公式 | 说明 |
|---|---|
| 容量 = $`\text{每扇区字节} \times \text{每磁道扇区数} \times \text{磁道数}/\text{面} \times \text{面数}`$ | |
| 访问时间 $`T = T_{\mathrm{seek}} + T_{\mathrm{rot}} + T_{\mathrm{transfer}}`$ | |
| $`T_{\mathrm{rot}}(\text{平均}) = 1/(2 \times \mathrm{RPM}/60)`$ 秒 | 半圈 |
| $`T_{\mathrm{transfer}} = \text{每扇区字节数} / \text{传输速率}`$ | |
| 例：7200 RPM → $`T_{\mathrm{rot}}(\text{平均}) = 60/(2 \times 7200) = 4.17`$ ms | |

**SSD**
| 公式 | 说明 |
|---|---|
| 擦除单位 = 块（block），读写单位 = 页（page） | |
| 寿命 = 总擦写次数（P/E cycles） | |
| 写放大 = 实际写入量 / 逻辑写入量 | |

## 9. 高速缓存（第 6 章）⚠️⚠️

**参数关系**

| 公式 | 说明 |
|---|---|
| $`C = S \times E \times B`$ | 容量 = 组数 × 相联度 × 块大小 |
| $`S = 2^s`$，$`B = 2^b`$ | 组数、块大小 |
| $`t = m - s - b`$ | 标记位数 |
| $`s = \log_2 S`$，$`b = \log_2 B`$ | |
| 地址 = $`[\text{tag}(t) \mid \text{set}(s) \mid \text{offset}(b)]`$ | $`m`$ 位物理地址 |
| 组号 = 块地址 $`\bmod S`$ | |

**性能**

| 公式 | 说明 |
|---|---|
| $`\mathrm{AMAT} = \text{命中时间} + \text{缺失率} \times \text{缺失惩罚}`$ | |
| 缺失率 = $`1 - \text{命中率}`$ | |
| 命中率 = $`\text{命中次数} / \text{总访问次数}`$ | |
| $`\mathrm{EAT} = h \cdot T_c + (1-h) \cdot T_m`$ | 有效访问时间 |
| 三类缺失：冷 / 冲突 / 容量 | |

**样例（务必背住解题格式）**
> $`m=32, C=64\mathrm{KB}, E=1, B=16`$ → $`b=4, S=4096, s=12, t=16`$

## 11. 虚拟内存与地址翻译（第 9 章）⚠️⚠️

| 公式 | 说明 |
|---|---|
| $`\mathrm{VA} = [\mathrm{VPN}(n-p) \mid \mathrm{VPO}(p)]`$ | $`p = \log_2(\text{页大小})`$ |
| $`\mathrm{PA} = [\mathrm{PPN} \mid \mathrm{PPO}]`$，$`\mathrm{PPO} = \mathrm{VPO}`$ | 页内偏移不变 |
| $`\mathrm{PPN} = \text{页表}[\mathrm{VPN}]`$ | 或 TLB 命中 |
| 页数 = $`2^{n-p}`$ | $`n`$ 位虚拟地址 |
| 页表大小 = $`\text{页表项数} \times \text{每项字节数}`$ | |
| 多级页表：$`\mathrm{VA} = [\mathrm{VPN}_1 \mid \mathrm{VPN}_2 \mid \dots \mid \mathrm{VPO}]`$ | 逐级索引 |
| i7：48 位 VA，4KB 页 → $`\mathrm{VPN}=36`$，4 级各 9 位 | |
| i7：2MB 大页 → $`\mathrm{VPO} = 21`$ 位 | |
| 单页表大小 = $`2^{n-p} \times \text{项大小}`$ | |
| TLB 索引 = VPN 低位；TLB tag = VPN 高位 | |

**TLB + 缓存组合命中**
| TLB | 页表 | 缓存 |
|---|---|---|
| 命中 | 不访问 | 命中/缺失 |
| 缺失 | 访问（页在内存） | — |
| 缺失 | 缺页 → 异常 → 重试 | — |

## 14. 系统总论（第 1 章）

| 公式 | 说明 |
|---|---|
| **Amdahl** $`S = 1/((1-\alpha) + \alpha/k)`$ | 全系统加速比 |
