## 专题 1：补码与整数运算全家桶

**核心一句话**：补码把"减法"变成"加模 $`2^w`$ 的加法"，让硬件只需加法器。

### 1.1 三种编码对照（w 位）

| 编码 | 表示范围 | 零的个数 | 运算 |
|---|---|---|---|
| 无符号 | $`[0, 2^w - 1]`$ | 1 | 模 $`2^w`$ 加法 |
| 原码 | $`[-(2^{w-1}-1), 2^{w-1}-1]`$ | 2（$`\pm 0`$） | 需单独处理符号 |
| 反码 | 同上 | 2 | 循环进位 |
| **补码** | $`[-2^{w-1}, 2^{w-1}-1]`$ | **1** | 统一加法 |

### 1.2 核心恒等式

$$
\begin{aligned}
-x &= \lnot x + 1 \quad \text{（取负）} \\
\mathrm{B2T}(x) &= -x_{w-1} \cdot 2^{w-1} + \sum x_i \cdot 2^i \\
\mathrm{T2U}(x) &= x + x_{w-1} \cdot 2^w \quad \text{（负数 }+2^w\text{）} \\
\mathrm{U2T}(u) &= u - u_{w-1} \cdot 2^w
\end{aligned}
$$

### 1.3 溢出判定三法

| 方法 | 正溢出 | 负溢出 |
|---|---|---|
| 结果符号法 | 正+正=负 | 负+负=正 |
| 双符号位（变形补码） | $`01`$ | $`10`$ |
| 进位法（单符号位） | $`C_s \oplus C_{s-1} = 1`$ | 同 |

（无符号溢出：结果 $`<`$ 任一操作数）

### 1.4 移位与乘除

| 运算 | 等价 | 注意 |
|---|---|---|
| $`x * 2^k`$ | $`x \ll k`$ | 溢出截断 |
| $`x / 2^k`$（无符号） | $`x \gg k`$ | 向下取整 |
| $`x / 2^k`$（有符号，C 语义向零） | $`(x + (1 \ll k)-1) \gg k`$ 当 $`x<0`$ | 加偏置 |
| $`x * C`$ | 移位+加减 | 编译器自动做 |

### 1.5 高频陷阱

1. **`-2147483648` 不是常量**：`-2147483648` 被解析为 `-(2147483648)`，而 `2147483648` 超出 int → 用 `INT_MIN` 或 `-2147483647-1`
2. **有符号/无符号混用**：比较和运算前隐式转无符号
3. **`abs(INT_MIN)` 溢出**：结果仍是 `INT_MIN`
4. **`x < 0` 比 `x >> 31` 更安全**（无符号时移位错误）
5. **循环下界**：`unsigned i` 递减到 0 再减会回绕成 UMax

## 专题 2：IEEE 754 浮点数与类型转换

### 2.1 通用解码公式

$$
V = (-1)^s \times M \times 2^E
$$
| 情况 | e 字段 | M | E |
|---|---|---|---|
| 规格化 | $`1 \sim 254`$（单） | $`1.f`$ | $`e - 127`$ |
| 非规格化 | $`0`$ | $`0.f`$ | $`-126`$ |
| 无穷 | $`255`$, $`f=0`$ | — | — |
| NaN | $`255`$, $`f \ne 0`$ | — | — |

### 2.2 解码练习

**单精度 `0xC0A00000`**
$$
s=1,\ e=1000\,0001=129,\ f=010\,0000\ldots=0.25
$$

$$
V = -1 \times 1.25 \times 2^{129-127} = -1.25 \times 4 = -5.0
$$

### 2.3 边界值表（单精度）

| 值 | 十六进制 |
|---|---|
| +0.0 | `0x00000000` |
| -0.0 | `0x80000000` |
| 最小非规格化正数 | `0x00000001` = $`2^{-149}`$ |
| 最小规格化正数 | `0x00800000` = $`2^{-126}`$ |
| 最大规格化 | `0x7F7FFFFF` $`\approx 3.4 \times 10^{38}`$ |
| $`+\infty`$ | `0x7F800000` |
| NaN | `0x7FC00000` |

### 2.4 类型转换矩阵

| From \ To | int | float | double |
|---|---|---|---|
| **int** | — | 可能舍入，不会溢出 | 精确（53位>32位） |
| **float** | 向零截断，超范围 UB | — | 精确 |
| **double** | 向零截断，超范围 UB | 可能舍入/溢出 | — |

⚠️ **注意**：`int → float` 会丢精度（float 只有 24 位有效位），如 `16777217` → `16777216.0f`。

### 2.5 浮点性质

- 加/乘法**不满足结合律、分配律**
- `x == x` 当 x 为 NaN 时为假
- `+0.0 == -0.0` 为真（但位模式不同）
- $`\infty - \infty`$、$`0 \times \infty`$、$`0/0`$ → NaN
- 向偶数舍入是默认模式

## 专题 3：数据对齐与结构体布局

### 3.1 对齐三原则

1. 成员偏移是**该成员对齐要求**（通常 = 自身大小）的整数倍
2. 结构体总大小是**最大成员对齐要求**的整数倍（尾部填充）
3. 数组元素的间隔 = `sizeof(T)`，所以 `sizeof` 必是其对齐的倍数

### 3.2 例题精讲

```c
struct A { char c; double d; int i; short s; };
```
| 成员 | 大小 | 偏移 | 说明 |
|---|---|---|---|
| c | 1 | 0 | |
| d | 8 | 8 | 需 8 对齐，补 7 字节 |
| i | 4 | 16 | |
| s | 2 | 20 | |
| 填充 | | 22~23 | 补齐到 8 的倍数 → **sizeof = 24** |

```c
struct B { double d; int i; short s; char c; };
```
| 成员 | 偏移 |
|---|---|
| d | 0 |
| i | 8 |
| s | 12 |
| c | 14 |
| 填充 | 15~23 |
| **sizeof** | **24**（本可 16，但尾部要补齐到 8） |

💡 **重排后**：`{ double d; int i; short s; char c; }` → d(0) i(8) s(12) c(14) → 还是 24，但若去掉尾部要求（如 `#pragma pack`）可以 16。

### 3.3 位域（Bit Field）

```c
struct { unsigned a : 4; unsigned b : 4; unsigned c : 8; };  // 2 字节
```
- 省空间，但访问慢，且位域布局是实现相关的

### 3.4 union 的用途

```c
union { float f; unsigned u; };   // 看 float 的位模式
union { unsigned u; unsigned char c[4]; };  // 判字节序
```
- 大小 = 最大成员（并满足对齐）

## 专题 4：x86-64 栈帧与过程调用约定

### 4.1 调用约定速查

| 项目 | 规定 |
|---|---|
| 参数寄存器 | `%rdi, %rsi, %rdx, %rcx, %r8, %r9` |
| 浮点参数 | `%xmm0 ~ %xmm7` |
| 返回值 | `%rax`（整数/指针），`%xmm0`（浮点） |
| 调用者保存 | `%rax %rcx %rdx %rsi %rdi %r8 %r9 %r10 %r11` |
| 被调用者保存 | `%rbx %rbp %r12 %r13 %r14 %r15` |
| 栈对齐 | `call` 前 `%rsp` 16 字节对齐 |
| 第 7+ 参数 | 从右向左压栈 |

### 4.2 标准函数序/尾声

```asm
foo:
    pushq  %rbp            # 保存调用者帧基址
    movq   %rsp, %rbp      # 建立新帧
    subq   $16, %rsp       # 分配局部空间（并保持对齐）
    ...
    leave                  # = movq %rbp,%rsp; popq %rbp
    ret
```

### 4.3 栈帧内容（从低到高）

```
[rsp]        局部变量 / 临时空间
[rbp-8]      ...
[rbp]        保存的调用者 rbp   ← rbp 指向此处
[rbp+8]      返回地址
[rbp+16]     第 7 个参数
[rbp+24]     第 8 个参数 ...
```

### 4.4 常见考题类型

1. **给 C 代码写汇编**（重点：循环、条件、数组）
2. **给汇编还原 C**（识别 `lea` 的算术、`cmp`+`set` 的比较、跳转模式）
3. **找栈溢出点**：局部数组 + 无边界检查函数
4. **为什么 `%rsp` 有偶数次 `push`**：对齐要求，反推参数个数

## 专题 5：流水线冒险与解决方法

### 5.1 冒险全景图

```
指令 i:  F  D  E  M  W
指令 i+1:   F  D  E  M  W
指令 i+2:      F  D  E  M  W
             ↑        ↑
          结构冒险   数据/控制冒险
```

### 5.2 数据冒险分类（按依赖类型）

| 类型 | 含义 | 例子 | 处理 |
|---|---|---|---|
| **RAW（真依赖）** | 后读前写 | `add %rax,%rbx` → `mov %rbx,%rcx` | 转发 / 停顿 |
| **WAR（反依赖）** | 后写前读 | 需寄存器重命名 | 乱序处理器用重命名 |
| **WAW（输出依赖）** | 后写前写 | 需重命名 | 同上 |

### 5.3 转发（Forwarding）细节

**转发来源**（按优先级 E > M > W）：
```
如果 E_dstE == D_srcA → valA = E_valE
否则如果 M_dstE/M_dstM == D_srcA → valA = M_valE/M_valM
否则如果 W_dstE/W_dstM == D_srcA → valA = W_valE/W_valM
否则 valA = R[rA]
```

**转发无法解决的**：**load/use 冒险**（结果在 M 阶段末才出来，下一条指令 E 阶段就要用）→ 停顿 1 周期。

### 5.4 控制冒险处理

| 方法 | 说明 | 优缺点 |
|---|---|---|
| 停顿 | 等分支确定 | 简单，性能损失大 |
| 预测不跳转（backward taken, forward not taken） | 顺序取指 | 需取消机制 |
| 分支历史表/BTB | 动态预测 | 准确率高 |
| 延迟分支 | 分支后固定执行一条 | 需编译器配合 |

**取消（Canceling）**：预测错误时把 D 阶段注入 bubble，清除该指令。

### 5.5 异常与流水线

- 精确异常：让流水线中**异常指令之前的指令全部完成，之后的不改变状态**
- 异常在 E/M/W 阶段可能发生，需携带 `Stat` 字段逐级传递
- `ret` 指令是特殊的控制冒险（返回地址在 M 阶段才知道）

### 5.6 性能计算

$$
\text{理想流水线吞吐} = \text{每周期 1 条}
$$

$$
\text{实际} = 1 / (1 + \text{停顿周期数}/\text{指令数})
$$
例：若 25% 指令是 load 且紧接使用（停顿 1 周期），CPI = 1.25。

## 专题 6：高速缓存映射与地址划分

### 6.1 通用解题流程（⚠️ 必须形成肌肉记忆）

```
已知：地址位数 m、缓存参数（C、E、B 或 S、E、B）
Step1: b = log2(B)
Step2: s = log2(S)   （S = C / (E·B)）
Step3: t = m - s - b
Step4: 把地址写成二进制，按 [t | s | b] 切分
Step5: 组号 = s 的值；标记 = t 的值；字节内偏移 = b 的值
```

### 6.2 例题（直接映射）

> 参数：$`m = 32`$ 位地址，$`C = 64\mathrm{KB}`$，$`E = 1`$（直接映射），$`B = 16`$ 字节。
> $`S = 65536 / (1 \times 16) = 4096`$ 组。
> $`b = 4`$，$`s = 12`$，$`t = 32 - 12 - 4 = 16`$。
> 地址 `0x00C0FFEE`：
> - 二进制 `0000 0000 1100 0000 1111 1111 1110 1110`
> - 标记 `0000 0000 1100 0000` = `0x00C0`
> - 组索引 `1111 1111 1110` = `0xFFE`
> - 块偏移 `1110` = `0xE`

### 6.3 例题（组相联）

> 参数：$`C = 64\mathrm{KB}`$，$`E = 4`$（4 路组相联），$`B = 32`$。
> $`S = 65536/(4 \times 32) = 512`$，$`s = 9`$，$`b = 5`$。
> 地址 = $`[\text{tag} \mid \text{9位组号} \mid \text{5位偏移}]`$

### 6.4 缓存命中判断题

**给定访问序列，模拟缓存**（Cache Lab 核心）：
1. 把每个地址拆成 $`\text{tag}, \text{set}, \text{block}`$
2. 查对应组内是否有匹配 tag 且有效
3. 命中 → 更新 LRU；缺失 → 替换 LRU 行（或空行）

### 6.5 写操作分类

| 情形 | 写命中 | 写缺失 |
|---|---|---|
| **写回（write-back）** | 写缓存，置脏位 | **写分配**：取块入缓存再写 |
| **写直通（write-through）** | 写缓存 + 写下层 | **非写分配**：直接写下层 |

### 6.6 局部性优化

- **行优先遍历**二维数组
- **分块（blocking）** 矩阵乘法
- **减少步长**、顺序访问
- **循环交换**（loop interchange）改变访问顺序

## 专题 7：链接的全过程与符号解析

### 7.1 全链路

```
源文件 .c
  → 预处理 .i
  → 编译 .s
  → 汇编 .o  （ELF 可重定位目标文件：.text/.data/.bss/.symtab/.rel.*）
  → 链接（符号解析 + 重定位）
  → 可执行文件（程序头部表，段映射）
  → 加载（execve → mmap）
```

### 7.2 符号解析规则表

| 情况 | 结果 |
|---|---|
| 两个强符号同名 | ❌ 链接错误 |
| 强 + 弱同名 | ✅ 取强符号 |
| 两个弱符号同名 | ⚠️ 任选，可能出错 |
| 引用未定义符号 | ❌ undefined reference |

### 7.3 静态库解析顺序（核心考点）

```
ld main.o libfoo.a libbar.a
       ↑ 只解析 libfoo.a 中能解决 main.o 未定义符号的成员
```
- 若 `main.o` 引用 `foo`，`foo.o` 引用 `bar`，而命令是 `libbar.a libfoo.a`：
  - 扫描到 `libbar.a` 时 `bar` 还没被引用 → 丢弃
  - 扫描到 `libfoo.a` 时取出 `foo.o`，此时 `bar` 变未定义，但 `libbar.a` 已经扫过 → **报错**
- **解法**：调整顺序 `libfoo.a libbar.a`，或 `--start-group ... --end-group`，或 `-Wl,--whole-archive`

### 7.4 重定位计算

**R_X86_64_PC32**（PC 相对）：
$$
\text{写入值} = \mathrm{ADDR}(S) + \mathrm{addend} - \mathrm{ADDR}(\text{引用位置})
$$
**R_X86_64_32**（绝对）：
$$
\text{写入值} = \mathrm{ADDR}(S) + \mathrm{addend}
$$

### 7.5 动态链接要点

- **PIC**：模块内用 PC 相对；模块外用 GOT/PLT
- **GOT**：存外部符号地址的表
- **PLT**：外部函数调用的跳转表，配合延迟绑定
- **延迟绑定**：首次调用才解析（`_dl_runtime_resolve`）
- **打桩**：编译时（宏）/ 链接时（`--wrap`）/ 运行时（`LD_PRELOAD`）

## 专题 8：进程、fork 与信号

### 8.1 fork 判定法

- 每次 `fork` 使进程数**翻倍**
- 判断某段代码执行次数：画出**进程图**，沿路径计数
- ⚠️ 注意 `fork` 在循环里、以及 `fork` 返回值的分支

**经典题**
```c
for (i = 0; i < 3; i++) fork();
// 总进程数 = 2^3 = 8，父进程输出 1 次，子进程各输出…（画图分析）
```

### 8.2 fork + execve + waitpid 模板

```c
pid_t pid = fork();
if (pid == 0) {
    // 子进程：执行新程序
    if (execve(path, argv, envp) < 0) { perror("execve"); exit(1); }
} 
// 父进程：等待
int status;
waitpid(pid, &status, 0);
```

### 8.3 信号处理模板（避免竞态）

```c
volatile sig_atomic_t flag = 0;
void handler(int sig) { flag = 1; }   // 只设标志，不做复杂操作

int main() {
    struct sigaction act;
    act.sa_handler = handler; sigemptyset(&act.sa_mask); act.sa_flags = 0;
    sigaction(SIGCHLD, &act, NULL);
    // 阻塞信号保护临界区
    sigset_t mask, prev;
    sigemptyset(&mask); sigaddset(&mask, SIGCHLD);
    sigprocmask(SIG_BLOCK, &mask, &prev);
    // ... 临界区 ...
    sigprocmask(SIG_SETMASK, &prev, NULL);
}
```

### 8.4 僵尸进程防治

```
SIGCHLD 到达 → 父进程必须调用 waitpid 回收
（若不回收，子进程变僵尸，占用内核进程表）
用 while ((pid = waitpid(-1, &status, WNOHANG)) > 0) 回收所有已终止子进程
```

### 8.5 常见考点

- fork 后**共享**什么、**独立**什么（文件描述符共享，文件表项共享，文件位置共享）
- `printf` 缓冲区在 fork 后的重复输出问题（子进程复制了缓冲区）
- 信号处理函数中**不可重入**函数的危险（`printf`、`malloc`）

## 专题 9：虚拟内存与地址翻译

### 9.1 核心公式链

$$
\mathrm{VA} = [\mathrm{VPN} \mid \mathrm{VPO}] \qquad \mathrm{PA} = [\mathrm{PPN} \mid \mathrm{PPO}] \qquad \mathrm{PPO} = \mathrm{VPO}
$$

$$
\mathrm{PPN} = \text{页表}[\mathrm{VPN}] \qquad \text{（或 TLB 命中直接得）}
$$

### 9.2 地址翻译解题流程（⚠️ 考研/期末必考大题）

```
给定：VA 位数、页大小、页表级数、各表基址、TLB 参数
Step1: 拆分 VA 得到各 VPN 和 VPO
Step2: 从一级页表基址出发，逐级用 VPN 索引
Step3: 读取最终 PTE，得到 PPN（注意有效位、权限位）
Step4: 合成 PA = PPN ‖ VPO
Step5: 如果考缓存：再用 PA 拆 [tag|set|offset] 判命中
```

### 9.3 TLB 与缓存的四个命中组合

| TLB | 缓存 | 结果 |
|---|---|---|
| 命中 | 命中 | 最快 |
| 命中 | 缺失 | PPN 已知，从内存取块 |
| 缺失 | （页在内存） | 查页表得 PPN，再访存 |
| 缺失 | 缺页 | 从磁盘取页（异常） |

### 9.4 多级页表计算题

> 例：32 位 VA，4KB 页（12 位偏移），两级页表，每级 10 位、10 位、12 位。
> - 一级页表 1024 项，二级页表最多 1024 项
> - 若某进程只用了 1 个 4MB 区域，只需 1 个二级页表 + 1 个一级页表 → 省内存

### 9.5 mmap 与 COW

| 场景 | 机制 |
|---|---|
| `fork` | 私有映射，COW |
| 共享内存 IPC | `MAP_SHARED` |
| `execve` 加载 | 代码/数据映射文件，栈/`.bss` 映射匿名页 |
| `malloc` 大块 | `mmap` 匿名页 |

### 9.6 常见考点

- 缺页是**故障**，处理后**重新执行**指令
- TLB 命中不需要访问页表，但**不一定缓存命中**
- 虚拟地址空间布局：代码段、数据段、堆（向上）、共享库、栈（向下）、内核区
- 页表项权限位（R/W/X/U）实现**内存保护**

## 专题 10：动态内存分配器设计

### 10.1 设计权衡

| 目标 | 冲突 |
|---|---|
| 吞吐率（快） | 空间利用率 |
| 空间利用率 | 实现复杂度 |

### 10.2 块格式（带边界标签）

```
已分配块:
┌────────────┬──────────────┐
│ 头(8B)      │ 载荷          │  ← 头 = 大小 | 0
└────────────┴──────────────┘
空闲块:
┌────────────┬──────────────┬────────────┐
│ 头(8B)      │ 前驱指针 + 后继指针 │ 尾(8B)     │
└────────────┴──────────────┴────────────┘
```
- 头/尾各存 $`\text{大小} \mid \text{分配位}`$，最高位（或最低位）做分配标志
- **为什么需要边界标签**：O(1) 判断前后块是否空闲，支持合并

### 10.3 合并四种情况

| 前块 | 后块 | 操作 |
|---|---|---|
| 已分配 | 已分配 | 不合并 |
| 空闲 | 已分配 | 与前合并 |
| 已分配 | 空闲 | 与后合并 |
| 空闲 | 空闲 | 三者合并 |

### 10.4 放置策略对比

| 策略 | 优点 | 缺点 |
|---|---|---|
| 首次适配 | 快、简单 | 易在头部堆积小碎片 |
| 下次适配 | 分散分配 | 空间利用率差 |
| 最佳适配 | 利用率高 | 扫描慢，产生小碎片 |

### 10.5 显式空闲链表

- 空闲块内维护 `pred`/`succ` 指针
- 分配时间：首次适配 O(空闲块数)；**后进先出（LIFO）** 插入 O(1)
- 合并仍需边界标签（O(1) 找前驱）

### 10.6 分离空闲链表

- 按大小类（size class）维护多个链表，如 $`\{1\text{-}16, 17\text{-}32, 33\text{-}64, \ldots\}`$
- 分配：先查对应大小类 → O(1) 分配
- 释放：按大小插入对应类
- 大幅减少碎片、加快分配，是现代分配器（如 glibc）的基础

### 10.7 分配器性能指标

$$
\text{内存利用率} = \text{峰值已分配载荷} / \text{堆大小}
$$

$$
\text{吞吐率} = \text{每秒完成的分配/释放操作数}
$$

### 10.8 常见考题

1. 给定分配序列，模拟首次适配/最佳适配的堆布局
2. 计算内部/外部碎片
3. 给定块格式，写出 `free` 的合并代码
4. 判断某个 `sizeof` 会在堆上占多少（含头部对齐）
5. malloclab：实现一个高分的分配器
