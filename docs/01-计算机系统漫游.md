# 第 1 章 计算机系统漫游

> 对应课程：短系列 1-1 ~ 1-4（4P）
> 本章是全书的"地图"，建立**整机视角**：一个 C 程序从源码到运行，究竟经历了什么。

---

## 1.1 程序的编译系统（The Compilation System）

一个 `hello.c` 要变成可执行的 `hello`，经过四个阶段：

| 阶段 | 程序 | 输入 → 输出 | 做什么 |
|---|---|---|---|
| 预处理 | `cpp` | `hello.c` → `hello.i` | 展开 `#include`、`#define` 宏，删除注释 |
| 编译 | `cc1` | `hello.i` → `hello.s` | 生成**汇编代码**（文本形式的机器指令） |
| 汇编 | `as` | `hello.s` → `hello.o` | 汇编器翻译成**机器指令**，打包成可重定位目标文件 |
| 链接 | `ld` | `hello.o` + 库 → `hello` | 合并多个目标文件与库函数（如 `printf`），生成可执行文件 |

```
hello.c ──cpp──> hello.i ──cc1──> hello.s ──as──> hello.o ──ld──> hello
        预处理          编译            汇编            链接
```

⚠️ **考点**：四个阶段的顺序、工具名、产物后缀；链接阶段把 `printf.o` 这样预编译好的目标文件合并进来。

💡 **为什么程序员要懂编译系统**
- 优化程序性能（第 5 章）
- 理解链接时错误（第 7 章）
- 避免安全漏洞（缓冲区溢出，第 3 章）

## 1.2 硬件组成（Hardware Organization）

以运行 `hello` 为例，一台典型系统的五大部件：

| 部件 | 作用 |
|---|---|
| **总线（Bus）** | 传送定长字节块（字，word），连接各部件 |
| **I/O 设备** | 输入/输出，通过**控制器/适配器**接到总线；每个设备有唯一 I/O 端口地址 |
| **主存（Main Memory）** | 临时存储，物理上是**线性字节数组**，每个字节有唯一地址 |
| **处理器（CPU）** | 解释/执行主存中的指令 |
| **寄存器文件（Register File）** | CPU 内部的小型高速存储 |

**CPU 核心部件**
- **PC（程序计数器）**：指向下一条要执行的指令
- **ALU（算术逻辑单元）**：计算新的数据和地址值
- **寄存器文件**：存放临时数据

⚠️ **`hello` 的执行流程**（经典简答题）
1. 键盘输入 `./hello`，shell 读入字符到寄存器 → 存入主存
2. 敲回车，shell 加载可执行文件：**可执行文件从磁盘 → 主存**
3. 加载完毕，CPU 从主存逐条取指令、执行，把 `hello, world\n` 写到寄存器文件 → 主存 → 显示设备
4. 关键点：**DMA（直接存储器存取）**技术让数据直接从磁盘到主存，**不经过 CPU**

💡 早期用 DMA 后 CPU 从"搬运工"解放出来，是理解 I/O 效率的起点。

## 1.3 存储层次结构与缓存（Memory Hierarchy & Cache）

**核心矛盾**：处理器追求快，存储器做大就慢，做快就贵。
**解决**：层次化 + 缓存——把常用数据放在小而快的存储器里。

层次从上到下：

```
寄存器  →  L1 Cache  →  L2 Cache  →  L3 Cache  →  主存  →  磁盘
更快/更小/更贵  ─────────────────────────────────────>  更慢/更大/更便宜
```

⚠️ **关键结论**
- **缓存（Cache）**：把下一层的数据暂存到上一层，是层次结构的通用思想。
- **局部性（Locality）**：程序倾向于访问刚刚访问过的数据或其附近数据，缓存能生效的根本原因。
- L1 一般用 **SRAM**，主存用 **DRAM**，磁盘是机械/固态设备。

## 1.4 操作系统抽象（Operating System）

操作系统是**应用程序与硬件之间的软件层**，它不直接"做"计算，而是提供抽象：

| 抽象 | 对应的硬件 | 说明 |
|---|---|---|
| **进程（Process）** | 处理器 + 主存 + I/O 设备 | 对"正在运行的程序"的抽象，让程序独占 CPU 的假象 |
| **虚拟内存（Virtual Memory）** | 主存 + 磁盘 | 每个进程看到一致的、私有的线性地址空间 |
| **文件（File）** | I/O 设备 | 对 I/O 设备的统一抽象，磁盘/键盘/网络都是"文件" |

**文件系统**：管理磁盘上文件的机制。

⚠️ **并发与并行**
- **并发（Concurrency）**：宏观上同时进行，微观上可交错。
- **并行（Parallelism）**：真正同时进行。
- 三种层次：**线程级并发** → **指令级并行** → **SIMD 数据级并行**。

**Amdahl 定律**（⚠️ 高频）

$$
S = 1 / ((1-\alpha) + \alpha/k)
$$

- $`\alpha`$：可加速部分占比；$`k`$：该部分的加速倍数；$`S`$：整体加速比。
- 结论：**系统的整体加速上限受不可加速部分制约**，$`k \to \infty`$ 时 $`S \to 1/(1-\alpha)`$。
