# 第 3 章 程序的机器级表示

> 对应课程：短系列 3-1 ~ 3-10（10P）｜直播版 P5 ~ P11（含 bomblab）
> 本章是**汇编 + 反汇编**的核心：从 C 到 x86-64 汇编，理解栈帧、数组、结构体与安全漏洞。

---

## 3.1 历史与概述

- **Intel x86** 系列是主流 CISC 架构，从 8086（16 位）演化到 x86-64（64 位）。
- **AT&T 格式 vs Intel 格式**（本课用 AT&T）：
  - AT&T：`movq %rsp, %rbp`（源在前、目的在后，寄存器带 `%`，立即数带 `$`）
  - Intel：`mov rbp, rsp`

📌 **数据格式后缀**（⚠️ 高频，决定操作数宽度）

| C 类型 | 汇编后缀 | 位宽 | 寄存器示例 |
|---|---|---|---|
| char | `b`（byte） | 8 | `%al` |
| short | `w`（word） | 16 | `%ax` |
| int | `l`（long word） | 32 | `%eax` |
| long / 指针 | `q`（quad word） | 64 | `%rax` |
| float | `s`（single） | 32 | `%xmm0` |
| double | `d` | 64 | `%xmm0` |

💡 注意 AT&T 中 `l` 表示 4 字节（long word），`q` 才是 8 字节。

## 3.2 寄存器与数据传送指令

### 3.2.1 x86-64 寄存器（16 个通用寄存器）

| 64 位 | 32 位 | 16 位 | 8 位 | 用途 |
|---|---|---|---|---|
| `%rax` | `%eax` | `%ax` | `%al` | 返回值 |
| `%rbx` | `%ebx` | `%bx` | `%bl` | 被调用者保存 |
| `%rcx` | `%ecx` | `%cx` | `%cl` | 第 4 参数 |
| `%rdx` | `%edx` | `%dx` | `%dl` | 第 3 参数 |
| `%rsi` | `%esi` | `%si` | `%sil` | 第 2 参数 |
| `%rdi` | `%edi` | `%di` | `%dil` | 第 1 参数 |
| `%rbp` | `%ebp` | `%bp` | `%bpl` | 被调用者保存（栈帧基址） |
| `%rsp` | `%esp` | `%sp` | `%spl` | **栈指针** |
| `%r8 ~ %r15` | `%r8d ~ %r15d` | … | `%r8b ~` | 参数/临时 |

⚠️ **调用者保存 vs 被调用者保存**
- 调用者保存：`%rax, %rcx, %rdx, %rsi, %rdi, %r8~%r11`（函数可随意改）
- 被调用者保存：`%rbx, %rbp, %r12~%r15`（函数要用必须保存/恢复）

### 3.2.2 操作数指示符（寻址方式）⚠️⚠️

通用形式：$`Imm(r_b, r_i, s)`$ → 地址 = $`Imm + R[r_b] + R[r_i] \cdot s`$

| 形式 | 汇编 | 计算的值 |
|---|---|---|
| 立即数 | `$Imm` | $`Imm`$ |
| 寄存器 | `%rax` | $`R[rax]`$ |
| 绝对 | `Imm` | $`M[Imm]`$ |
| 间接 | `(%rax)` | $`M[R[rax]]`$ |
| 基址+偏移 | `8(%rax)` | $`M[R[rax] + 8]`$ |
| 变址 | `(%rax,%rdx,4)` | $`M[R[rax] + R[rdx] \cdot 4]`$ |
| 完整 | `8(%rax,%rdx,4)` | $`M[R[rax] + R[rdx] \cdot 4 + 8]`$ |

💡 比例因子 $`s \in \{1,2,4,8\}`$，正好对应 char/short/int/long 的字节数。

### 3.2.3 数据传送指令

| 指令 | 说明 |
|---|---|
| `mov S, D` | 传送（源→目的），不能内存到内存 |
| `movz S, D` | **零扩展**传送（小→大） |
| `movs S, D` | **符号扩展**传送 |
| `movabsq $Imm, %r` | 传送 64 位立即数 |

📌 `movs`/`movz` 需要两个后缀：源宽度 + 目的宽度，如 `movzbl`（1 字节零扩展到 4 字节）。
📌 `cltq` = 把 `%eax` 符号扩展到 `%rax`（等价 `movslq %eax, %rax`）。

### 3.2.4 压栈/出栈

```
pushq S   ≡  R[%rsp] ← R[%rsp] - 8;  M[R[%rsp]] ← S
popq D    ≡  D ← M[R[%rsp]];  R[%rsp] ← R[%rsp] + 8
```
⚠️ **栈向低地址增长**（`%rsp` 减小时栈"变高"）。

## 3.3 算术与逻辑运算指令

| 指令 | 效果 | 说明 |
|---|---|---|
| `leaq S, D` | `D ← &S`（地址） | **不访存**，常用于算术 |
| `inc/dec` | `+1 / -1` | |
| `neg` | 取负 | |
| `add/sub/imul` | 加/减/乘 | |
| `sal/shl` | 左移 | 等价 |
| `sar` | 算术右移 | 补符号位 |
| `shr` | 逻辑右移 | 补 0 |
| `xor/and/or` | 位运算 | |
| `imulq S, D` | 有符号乘 | |

⚠️ **`leaq` 的妙用**：因为不访问内存，编译器用它做算术。
```asm
leaq 0x0(,%rdi,4), %rax   # rax = 4*rdi
leaq 7(%rdi,%rdi,2), %rax # rax = 3*rdi + 7
leaq (%rdi,%rdi,2), %rax  # rax = 3*rdi
```

⚠️ **乘法分为两类**
- 双操作数 `imulq S, D`：`D ← D * S`，截断到 64 位
- 单操作数 `imulq S`：**128 位结果**，存 `%rdx:%rax`（高 64 位在 `%rdx`）
- 无符号 `mulq`；除法 `idivq`（`%rdx:%rax` $`\div`$ S，商在 `%rax`，余数在 `%rdx`）

## 3.4 条件码与比较指令

### 3.4.1 条件码寄存器（EFLAGS）

| 标志 | 名称 | 含义 |
|---|---|---|
| **CF** | 进位标志 | 无符号运算最高位进位/借位 |
| **ZF** | 零标志 | 结果 = 0 |
| **SF** | 符号标志 | 结果最高位（负数） |
| **OF** | 溢出标志 | 补码溢出 |

**设置条件码的指令**
- `cmp S1, S2`：根据 `S2 - S1` 设置条件码（**不保存结果**）
- `test S1, S2`：根据 `S1 & S2` 设置（常用 `test %rax, %rax` 判零/判负）

### 3.4.2 读取条件码

**set 指令**（结果写入 1 字节寄存器）：`sete/setz`、`setne/setnz`、`sets`、`setns`、`setg/setge/setl/setle`（有符号）、`seta/setae/setb/setbe`（无符号）。

⚠️ **有符号 vs 无符号比较**（高频）

| 含义 | 有符号 | 无符号 | 条件 |
|---|---|---|---|
| 相等 | `e` | `e` | ZF |
| 小于 | `l` | `b` | $`SF \ne OF`$ / CF |
| 小于等于 | `le` | `be` | ZF或$`SF \ne OF`$ / CF或ZF |
| 大于 | `g` | `a` | $`ZF=0`$且$`SF=OF`$ / $`CF=0`$且$`ZF=0`$ |

💡 **记忆**：有符号用 `l/g`（less/greater），无符号用 `b/a`（below/above）。

## 3.5 跳转指令与循环

### 3.5.1 跳转

| 指令 | 条件 |
|---|---|
| `jmp` | 无条件 |
| `je/jz` | ZF |
| `jne/jnz` | ~ZF |
| `js/jns` | SF / ~SF |
| `jg/jge/jl/jle` | 有符号 |
| `ja/jae/jb/jbe` | 无符号 |

**跳转方式**：直接跳转（标号）、间接跳转（`jmp *%rax`、`jmp *(%rax)`）。

📌 **PC 相对寻址**：跳转目标编码为相对下一条指令的偏移量，利于位置无关代码。

### 3.5.2 三种循环的汇编形式

| C 形式 | 汇编模式 |
|---|---|
| **do-while** | 循环体 → 测试条件 → 跳回（最自然） |
| **while** | 两种编译：跳转到测试 / guarded-do |
| **for** | 等价 while（初始化 → 测试 → 更新） |
| **switch** | **跳转表（jump table）**，`jmp *.L4(,%rdi,8)`，O(1) 分派 |

## 3.6 过程（函数调用）⚠️⚠️

### 3.6.1 运行时栈与栈帧

```
高地址
    ...            调用者的栈帧
    ┌──────────┐
    │  参数7+   │
    ├──────────┤
    │ 返回地址  │ ← call 压入
    ├──────────┤
    │ 保存的rbp │ ← pushq %rbp
    │          │ ← %rbp 指向这里
    │ 局部变量  │
    │ ...      │
    │          │ ← %rsp
    └──────────┘
低地址
```

**调用过程**
1. **调用者**：参数放寄存器（超过 6 个入栈）；`call` 把**返回地址**压栈
2. **被调用者**：`pushq %rbp` 建立栈帧；保存被调用者寄存器；分配局部空间
3. **返回**：`leave`（= `movq %rbp,%rsp; popq %rbp`）+ `ret`（弹出返回地址）

### 3.6.2 参数传递（⚠️ 高频）

前 6 个整型/指针参数顺序：
```
%rdi → %rsi → %rdx → %rcx → %r8 → %r9
```
第 7 个及以后**通过栈传递**（调用者压栈）。

浮点参数用 `%xmm0 ~ %xmm7`。

### 3.6.3 栈对齐

⚠️ **x86-64 要求：调用 `call` 之前 `%rsp` 必须 16 字节对齐**（ABI 规定）。这就是为什么 `main` 里有时会看到 `subq $8, %rsp`（补 8 字节对齐）。

### 3.6.4 递归

每次递归调用创建新的栈帧，$`n!`$、`fib` 均可直接映射。**栈深度 = 递归深度**，过深会**栈溢出**。

## 3.7 数组的分配和访问

### 3.7.1 一维数组

```c
T A[N];    // 元素大小 sizeof(T) = L
```
- 起始地址 $`x_A`$，元素 $`i`$ 地址 = $`x_A + L \cdot i`$
- 汇编：`movl (%rdi,%rsi,4), %eax` 取 `A[i]`（int，s=4）

### 3.7.2 指针运算

```c
&A[i] ≡ A + i       // 指针 + 整数 = 地址 + i*sizeof(T)
A[i] ≡ *(A + i)
```
📌 `&A[i]` 与 `A+i` 值相同，但类型不同；指针减法结果要除以元素大小。

### 3.7.3 多维数组

```c
T A[R][C];   // 行优先（row-major）存储
```
- 元素 $`A[i][j]`$ 地址 = $`x_A + L \cdot (C \cdot i + j)`$
- 内存中按行连续排列

**多维数组的访问优化**：按行遍历比按列遍历**局部性好得多**（配合第 6 章缓存理解）。

## 3.8 结构体与联合体（⚠️ 数据对齐）

### 3.8.1 结构体布局与对齐

**对齐规则**（x86-64）：
1. 每个成员的偏移量必须是其**自身大小**的整数倍（若成员对齐要求 `K` 字节，则偏移是 `K` 的倍数）
2. 结构体总大小必须是**最大成员对齐要求**的整数倍（尾部填充）
3. 编译器可能重排成员以减少填充（但 C 标准不保证）

⚠️ **对齐原因**：硬件访问未对齐数据效率低甚至出错；保证一次内存访问完成。

**例题（高频）**
```c
struct S1 { char c; int i; char d; };
// c(0) 填充3 i(4-7) d(8) 尾部填充3 → sizeof = 12

struct S2 { int i; char c; char d; };
// i(0-3) c(4) d(5) 尾部填充2 → sizeof = 8

struct S3 { char c; char d; int i; };
// c(0) d(1) 填充2 i(4-7) → sizeof = 8
```
💡 结论：**把大成员放前面、相同类型放一起**能减少填充。

### 3.8.2 联合体 union

- 所有成员**共享同一块内存**，大小 = 最大成员大小（还要满足对齐）
- 用途：节省空间、类型双关（type punning，如把 float 的位按 int 读）
- 也可用来**判断字节序**

### 3.8.3 数据对齐（Alignment）

- 全局变量：编译器保证按 `K` 对齐
- 栈上变量：通过调整 `%rsp` 对齐
- `malloc` 返回的地址保证 16 字节对齐（x86-64）
- `_Alignas` / `__attribute__((aligned))` 可强制对齐

## 3.9 缓冲区溢出与安全 ⚠️

### 3.9.1 原理

```c
char buf[8];
gets(buf);   // 不检查长度 → 可写穿
```
栈上缓冲区溢出会**覆盖返回地址**，攻击者可注入并执行恶意代码（**代码注入攻击**）。

**栈帧示意**
```
低地址 ... [buf 8字节][%rbp][返回地址] 高地址
                        ↑ 溢出后覆盖这里
```

### 3.9.2 防御手段（⚠️ 高频）

| 手段 | 原理 |
|---|---|
| **栈随机化（ASLR）** | 每次运行栈地址随机，攻击者无法确定注入代码/返回地址 |
| **栈破坏检测（Stack Canary）** | 返回地址前放哨兵值，函数返回前检查是否被改 |
| **不可执行栈（NX / DEP）** | 栈段标记为不可执行，注入的代码无法运行 |
| **地址空间布局随机化** | 段基址随机化 |
| **`fgets`/`strncpy` 替代** | 限制写入长度（编程层面） |
| **返回导向编程（ROP）防御** | 更复杂，现代还有 CFI |

💡 **Canary 结构**：`gs:0x28` 取哨兵 → 存栈 → 返回前比对 → 不等则 `__stack_chk_fail`。

## 本章速记

- 6 个参数寄存器：**rdi, rsi, rdx, rcx, r8, r9**；第 7 个起入栈
- 寻址 $`Imm(r_b, r_i, s)`$；`leaq` 不访存，用于算术
- 条件码 **CF/ZF/SF/OF**；有符号 `l/g`，无符号 `b/a`
- 栈**向低地址增长**；`call` 压返回地址；调用前 `%rsp` **16 字节对齐**
- 结构体大小 = 最大对齐要求的整数倍，注意填充
- 缓冲区溢出防御：**ASLR · Canary · NX**
