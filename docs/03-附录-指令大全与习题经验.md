# 第 3 章附录：x86-64 指令大全 & 习题解题经验

> 来源：课后习题 **3.26 / 3.28 / 3.30 / 3.31 / 3.32 / 3.33 / 3.34 / 3.35 / 3.38 / 3.40 / 3.41 / 3.42 / 3.43 / 3.46** 的逐题讲解沉淀。
> 第一部分：本章涉及（+ 同类相关）的汇编指令速查；第二部分：按题型整理的解题套路；第三部分：高频陷阱；第四部分：一页答案速查。

**约定**：`S` = 源操作数，`D` = 目的操作数；后缀 `b/w/l/q` = 1/2/4/8 字节；`M[x]` 表示读地址 x 处的内存。

## 第一部分　指令大全

### 1.1 数据传送

| 指令 | 效果 | 要点 / 陷阱 | 出场 |
|---|---|---|---|
| `mov S, D` | $`D \leftarrow S`$ | 不能内存→内存；寄存器宽度须匹配后缀 | 全部题 |
| `movabsq $Imm, %r` | 传送 64 位立即数 | 只有它能把任意 64 位常数装进寄存器 | — |
| `movz S, D` | **零**扩展传送 | 后缀两个：源宽度+目的宽度，如 `movzbq` | — |
| `movs S, D` | **符号**扩展传送 | `movslq`（int→long）认参数类型的钥匙 | 3.33 |
| `cltq` | `%eax` 符号扩展到 `%rax` | 等价 `movslq %eax, %rax`，编码更短 | — |

📌 **32 位写入自动清零高 32 位**：`movl $0, %eax` 执行后 `%rax = 0`。但注意是**零**扩展——`movl $-1, %eax` 后 `%rax = 0x00000000FFFFFFFF`，**不是** −1（想带符号必须显式 `movslq`）。8/16 位写入（`%al`/`%ax`）则**其余位不变**。（3.40 问答）

### 1.2 地址计算

| 指令 | 效果 | 要点 |
|---|---|---|
| `leaq D(%rb,%ri,s), D` | $`D \leftarrow D + R[\%rb] + R[\%ri] \cdot s`$ | **不访存**，纯算地址；也是"三操作数加法器"（`(%rdx,%rsi)` = c+b，3.31） |

出场：3.38（凑系数 5j）、3.40（val/偏移计算）、3.41（`&sp->s.x`）、3.43（取地址）、3.34（x+i）。

📌 反推时见 `leaq` 一律先想"算地址 / 加法"，绝不读内存。

### 1.3 算术与逻辑

| 指令 | 效果 | 出场 |
|---|---|---|
| `addq S, D` / `addl` | $`D \leftarrow D + S`$ | 3.28(val<<1 用 addq %rax,%rax)、3.32 |
| `subq S, D` | $`D \leftarrow D - S`$ | 3.28(`subq $1,%rdx` 当循环递减)、3.34 |
| `imulq S, D` | $`D \leftarrow D \times S`$（双操作数） | 3.32 |
| `xorq S, D` | 异或 | 3.26(val^x)、3.31(b^15) |
| `orq S, D` | 或 | 3.28(val|低位) |
| `andl $1, %eax` | 与（取最低位） | 3.26(parity) |
| `inc` / `dec` | +1 / −1 | — |
| `neg` / `not` | 取负 / 按位取反 | —（相关未出场） |

💡 乘常数常被拆成 `leaq` + 移位/加减（强度削减）：$`7i = 8i - i`$ → `leaq 0(,%rdi,8)` + `subq`；$`5j = j + 4j`$ → `leaq (%rsi,%rsi,4)`（3.38）。

### 1.4 移位 ⚠️ 逻辑 vs 算术

| 指令 | 填充 | 对应 C 类型 | 出场 |
|---|---|---|---|
| `salq` / `shlq` | 左移，低位补 0 | 通用 | 3.28(`salq $2`)、3.31 |
| `shrq` | **逻辑**右移，高位补 0 | **unsigned** | 3.26、3.28、3.35 |
| `sarq` | **算术**右移，高位补符号 | **signed** | （对照项） |

⚠️ 反推 C 代码时 `shrq` ⇒ 无符号类型、`sarq` ⇒ 有符号类型，这是判断 signed/unsigned 的重要线索。

### 1.5 设置条件码（不写结果，只设标志）

| 指令 | 等价运算 | 常见用途 | 出场 |
|---|---|---|---|
| `cmpq S2, S1` | $`S1 - S2`$ 设标志 | 比较大小（注意 AT&T 顺序：**前减后**） | 3.30(`cmpq $8`)、3.31 |
| `testq S2, S1` | $`S1 \& S2`$ 设标志 | 判零（`testq %rdi,%rdi` = x==0?） | 3.26、3.35、3.42 |

💡 算术指令本身也设标志，所以 `subq $1,%rdx` + `jne` 一条当两用（3.28 的循环测试）。

### 1.6 条件跳转 jcc 全家 ⚠️

| 助记 | 含义 | 判定条件 | 有/无符号 |
|---|---|---|---|
| `je` / `jz` | 相等 / 为零 | ZF=1 | — |
| `jne` / `jnz` | 不等 / 非零 | ZF=0 | — |
| `js` / `jns` | 负 / 非负 | SF=1/0 | — |
| `jl` / `jnge` | 小于 | SF≠OF | 有符号 |
| `jle` / `jng` | 小于等于 | ZF=1 或 SF≠OF | 有符号 |
| `jg` / `jnle` | 大于 | ZF=0 且 SF=OF | 有符号 |
| `jge` / `jnl` | 大于等于 | SF=OF | 有符号 |
| `jb` / `jnae` | 低于 | CF=1 | 无符号 |
| `jbe` / `jna` | 低于等于 | CF=1 或 ZF=1 | 无符号 |
| `ja` / `jnbe` | 高于 | CF=0 且 ZF=0 | 无符号 |
| `jae` / `jnb` | 高于等于 | CF=0 | 无符号 |

⚠️ **无符号比较的妙用**：switch 跳转表越界检查用 `ja`——负数（如 x−(−1) 下溢成 0xFFFF…）按无符号解释是巨大值，一条 `ja` 同时拦住"太大"和"太小"（3.30、3.31）。

### 1.7 setcc 与 cmovcc（条件传送 ⚠️）

| 形式 | 效果 | 用途 |
|---|---|---|
| `setcc %al` | 条件成立则 $`%al \leftarrow 1`$，否则 0 | 把比较结果变成 0/1（条件表达式） |
| `cmovcc S, D` | 条件成立才 $`D \leftarrow S`$ | **条件传送**：无分支实现 if-else / 三值表达式（3.20、3.21 出场） |

📌 cmov 家族与 jcc 用同一套条件后缀；**判定读的是前一条 cmp/test 设置的标志位**，与被传送的操作数无关：

| 指令 | 条件 | 含义 |
|---|---|---|
| `cmove / cmovz` | ZF=1 | 相等 / 为零 |
| `cmovne / cmovnz` | ZF=0 | 不等 / 非零 |
| `cmovs` / **`cmovns`** | SF=1 / SF=0 | 负 / **非负** |
| `cmovg` / `cmovge` / `cmovl` / `cmovle` | 有符号 | 大于 / 大于等于 / 小于 / 小于等于 |
| `cmova` / `cmovae` / `cmovb` / `cmovbe` | 无符号 | 高于 / 高于等于 / 低于 / 低于等于 |

典型形态（3.20 的按符号选偏置）：

```text
    leaq   7(%rdi), %rax      # 先备好候选值 x+7（两条路都会先算好）
    testq  %rdi, %rdi         # 设 SF = x 的符号位
    cmovns %rdi, %rax         # x >= 0（SF=0）才改用 x 本身
```

⚠️ 三个考点：

1. **两条路都会被计算**——cmov 是"先算好两个候选值再挑选"，只有两边都廉价且无副作用时编译器才敢用；除法、函数调用、可能解引用空指针的分支必须回到真跳转（`cond ? *p : 0` 无分支执行会真的去读 `*p`）；
2. **cmov 只读不写标志位**，多条 cmov 可共享同一次 `cmp`；
3. **条件来自上一条设标志的指令**，与被传送的值无关。

💡 为什么存在：if-else 的跳转一旦被分支预测器猜错要冲刷流水线（15~20 周期惩罚）；cmov 无分支、不存在预测失误，min/max/abs/三值表达式都会生成它（`x/8` 向零舍入的偏置挑选正是 3.20）。

### 1.8 除法与全宽符号扩展（相关未出场）

| 指令 | 效果 |
|---|---|
| `cqto` | `%rdx:%rax ← 符号扩展(%rax)`（为除法准备被除数） |
| `idivq S` | 商→`%rax`，余数→`%rdx` |
| `divq S` | 无符号版 |

### 1.9 无条件跳转与跳转表

| 形式 | 效果 | 出场 |
|---|---|---|
| `jmp .L4` | 直接跳转 | 3.26(跳到中间) |
| `jmp *.L4(,%rdi,8)` | **间接跳转**：目标 = 表 + 下标×8 | 3.30、3.31 |

📌 跳转表 `D(,%ri,8)` 就是把 switch 的 case 标号做成 `.quad` 数组，用下标直接取目标地址——switch 题的全部核心。

### 1.10 过程与栈 ⚠️⚠️

| 指令 | 效果 | 出场 |
|---|---|---|
| `call Label` | 压**返回地址**（`%rsp −= 8`），跳转 | 3.32、3.34、3.35 |
| `ret` | 弹返回地址入 PC（`%rsp += 8`） | 3.32、3.35、3.46 |
| `pushq %rbx` | 压栈（`%rsp −= 8` 后存） | 3.34、3.35 |
| `popq %rbx` | 弹栈（读后 `%rsp += 8`） | 3.34、3.35 |
| `leave` | 等价 `movq %rbp,%rsp` + `popq %rbp`（相关未出场） | — |

⚠️ `rep; ret` / `repz retq`：`rep` 前缀放在 `ret` 上**无语义**，是 GCC 对旧 AMD 分支预测的优化写法，当普通 `ret` 读（3.28、3.32）。

### 1.11 寄存器约定速览

| 角色 | 寄存器 |
|---|---|
| 参数 1~6 | `%rdi, %rsi, %rdx, %rcx, %r8, %r9`（只看位置，与名字无关） |
| 返回值 | `%rax`（第 2 个返回值用 `%rdx`） |
| 被调用者保存 | `%rbx, %rbp, %r12, %r13, %r14, %r15`（共 **6** 个，要用必先 push 后 pop） |
| 调用者保存 | 其余全部（跨调用存活不能靠它们） |
| 栈指针 | `%rsp`，栈向**低地址**增长 |

## 第二部分　题型与解题经验

### 2.1 循环翻译题（3.26 while / 3.28 for）

**第一步永远是识别翻译方法**——先看入口，再看测试位置：

| 形态 | 入口特征 | 测试位置 | 编译级别 |
|---|---|---|---|
| jump-to-middle 跳转到中间 | 无条件 `jmp` 跳到测试 | 代码中部 | `-Og` |
| guarded-do 守卫式 | 入口处条件跳转跳过循环（守卫） | 底部（+入口一份） | `-O1` |
| do-while 直接翻译 | 无任何入口跳转，直接进循环体 | 底部唯一一份 | — |

- **补 C 代码**：初始化→`movl $Imm`；测试→`testq/cmpq + jcc` 反写条件；循环体→夹在标号之间的指令；更新→递增/递减指令。注意 `shrq`⇒unsigned。
- **"为什么没有初始测试/守卫"的标准答法**：初始条件使首次测试**恒为真**（如 i 初值 64、循环次数为编译期常量），编译器删掉可证明冗余的判断。
- **识别函数功能**：手动代 2~3 轮小例子，或写成数学式（如 3.26 = 全部位异或 = 奇偶性；3.28 = 位逆序）。

### 2.2 switch 跳转表题（3.30 / 3.31）

五步法：

1. 入口 `add/sub` 常数 ⇒ **平移量 = −最小标号**（无平移则最小标号为 0）；
2. `cmp $k` + `ja 目标` ⇒ 标号范围上限；**ja 的目标 = default 分支地址**；
3. 逐项列跳转表：指向 default 的项 = **填充项**（不是 case）；
4. 表项下标 + 平移量 ⇒ 还原各 case 标号；
5. **表内重复目标 = 共用代码的多个标号**。

三个高级特征（3.31）：

- **贯穿（fall through）**：某标号块结尾没有 `jmp/ret`、控制流直接落到下一块 ⇒ C 源码里 case A 后没写 break；
- **表项直通公共出口**（直接指向 `*dest = val` 的存栈指令）⇒ 该分支的 val 恰好等于某个**未修改的入口寄存器**（如 val = a，零开销分支）；
- val 放哪个寄存器看**公共出口读哪个**（如 `movq %rdi,(%rcx)` ⇒ val 在 %rdi）。

### 2.3 过程调用追踪题（3.32）

填表规则（表中数值均为**指令执行前**状态）：

- **%rsp 列**：初始值题目给；此后只有 `call`（−8）和 `ret`（+8）改变它，十六进制加减 8；
- **\*%rsp 列**：= **最近一个被压入、尚未弹出的返回地址** = 对应 `call` 的**下一条指令地址**（从反汇编地址列读；callq 编码 5 字节 ⇒ 下一条 = 本条+5）；无未弹返回地址时填 —；
- **数据寄存器列**：本条指令的效果写在下一行；参数寄存器在 call 前由 `lea/mov` 就地改造（如 `last(x−1, x+1)`）。

⚠️ 叶子函数+无局部存储 ⇒ 可能完全没有栈帧（无 push/sub），%rsp 全程只被 call/ret 动。

### 2.4 参数类型反推题（3.33）

1. **位置→寄存器**：`%rdi %rsi %rdx %rcx` 按位入座；
2. **扩展指令定数宽**：`movslq/movswq/movsbq` ⇒ int/short/char（指针永不符号扩展）；
3. **内存操作后缀定指针指向类型**：`q`→`long*`，`l`→`int*`，`w`→`short*`，`b`→`char*`；
4. **返回值常数反推 sizeof 配对**：`movl $6` 且一数已定为 int(4) ⇒ 另一数 2 字节 short。⚠️ `addb` 只说明目的地是 1 字节，**不能**定数值参数宽度（只加低 8 位是合法优化）；
5. **独立语句可重排** ⇒ 一份汇编两种答案（语句↔指令两种配对）。

### 2.5 栈帧与被调用者保存题（3.34）

- 开头一串 `pushq %rXX` = 保存 callee-saved（每个 8 字节）；`subq $N,%rsp` = 本地栈区；
- 局部值去向：`%rbx/%rbp/%r12~%r15` 共 **6 个**，用满即止，装不下（本题 8 个）→ 剩余写 `%rsp` 偏移；`leaq` 目的地必须是寄存器，故经 `%rax/%rdx` 中转（caller-saved，Q 可随便覆盖，值已落袋）；
- **C 问答法**：callee-saved 只有 6 个 < 8 个局部值；caller-saved 跨 `call` 不保 ⇒ 多出的必须上栈；
- **subq 大小核算**：实际所需凑到 16 的倍数（对齐），多出的 8 字节是填充（见 3.7 栈对齐）。

### 2.6 递归题（3.35）

递归函数四段模板，逐段对号：

```text
序幕   pushq %rbx; movq %rdi,%rbx      # 存旧值 + 把参数搬进 callee-saved
基例   testq + je                       # 递归出口（基例返回值常提前 movl $0,%eax）
递归   改小参数(shrq); call 自身; addq %rbx,%rax   # 递归 + 用存下的原参数合成结果
尾声   popq %rbx; ret                   # 还旧值
```

- **A 问（%rbx 存什么）**：几乎总是**本次调用的参数**——它必须在 `call` 之后还活着，只有 callee-saved 能保证；
- 功能识别：展开递推式（如 f(x)=x+f(x>>2) = 逐层 4 商之和，**不是**进制数位和——取商 vs 取余要分清）。

### 2.7 数组寻址反推题（3.38）

核心公式：`T A[R][C]` 行优先 ⇒ $`\&A[r][c] = A + (r\cdot C + c)\times sizeof(T)`$。

- **行号 i 的系数 = 数组的列数**：P[M][N] 中 i 的系数 ⇒ N；Q[N][M] 中 j 的系数 ⇒ M；
- 系数往往藏在 `leaq` 戏法里：$`7i = 8i - i`$、$`5j = j + 4j`$；
- ⚠️ 加载顺序 ≠ 语句顺序（两条独立加载可互换），只认下标表达式对号。

### 2.8 定长数组优化题（3.40）

- **对角线地址是等差数列**：$`\&A[i][i] = A + 4(N{+}1)i`$，步长 $`4(N{+}1)`$，终点 $`4N(N{+}1)`$（本题 68 / 1088，N=16）；
- 汇编特征：`movl $0,%eax` 初始化偏移 → 循环内 `mov 存值` + `addq $step` + `cmpq $end`，无乘法 ⇒ 归纳变量替换 + 强度削减；
- 写等价 C：基址指针 `int *Abase = &A[0][0]` + 元素下标步进 `N+1` + do-while + `!=` 测试；**常数一律用含 N 的表达式**（重新定义 N 后仍正确）；
- ⚠️ 陷阱：步长是 4(N+1) 不是 4N；终点是 4N(N+1) 不是 4N²。

### 2.9 结构体 / 联合体题（3.41 / 3.43）

固定流程：**画布局 → 算偏移 → 汇编常数对号入座**。

- struct：按声明顺序排，字段偏移须是自身大小（对齐）的倍数，不满足填 padding；总大小凑成最大对齐的倍数；
- union：所有成员从偏移 **0** 重叠，大小 = 最大成员（再凑对齐）；成员互相重叠是"跨成员读写"技巧的基础；
- 读指令三看：**偏移定字段、后缀定宽度（b/w/l/q）、`leaq` = 取地址**；指针解引用分两步（先 `movq` 取指针，再按宽度访问）；
- 数组名在表达式中退化为指针（`up->t2.a` ⇒ `leaq` 取地址）；变址寻址 `D(%rb,%ri,S)` 处理 `a[下标]`。

### 2.10 链表题（3.42）

结构体 `{ long v; struct ELE *p; }` = 单链表结点（v=0、p=8、共 16 字节）。

- **遍历一行指令**：`movq 8(%rdi),%rdi` —— 用当前结点的 next 覆盖指针自身；
- NULL 即全零 ⇒ `testq %rdi,%rdi` 判表尾零开销；
- 典型功能：沿链累加 `v`（while 遍历求和），循环多为 jump-to-middle 形态。

### 2.11 栈破坏 / 缓冲区溢出题（3.46）

- 先画栈图：**返回地址在上、保存的 callee-saved 次之、buf 在 %rsp 处**（`mov %rsp,%rdi` 定位 buf）；
- gets 从 buf 逐字节向上铺：**字符→ASCII（'0'~'9' = 0x30~0x39）→ 小端填格**；写入长度 = 字符数 + 1（`\0`）；
- 被改的返回地址 = 残留高字节 + 新写低字节按**小端**拼回（典型结果 0x4034）→ ret 时跳向无效地址段错误；
- 被破坏的寄存器 = 保存在栈上又被覆盖的那个（`popq` 恢复出垃圾）；
- 配套错误排查：`malloc(strlen(buf))` 少 1 字节（没给 `\0` 留位，应 +1）、未检查 malloc 返回 NULL。

## 第三部分　高频陷阱清单

1. **32 位写清零高位**：`movl $0,%eax` ⇒ %rax=0 ✓；但 `movl $-1,%eax` 后 %rax 是 +4294967295，不是 −1（要 `movslq`）。
2. **shrq vs sarq**：逻辑/算术右移 = 无符号/有符号，反推 C 类型的重要线索。
3. **ja 一石二鸟**：无符号比较让负下标变成巨值，越界检查一条搞定（switch 表）。
4. **leaq 不访存**：见 leaq 先想"算地址/三操作数加法"。
5. **术语撞名**：循环的"测试"（条件表达式）≠ `testq` 指令；测试可由 `testq/cmpq/subq` 任一设置标志实现。
6. **语句可重排**：无依赖的语句编译器可交换顺序 ⇒ 3.33 有两解、3.38 加载顺序与 C 相反。
7. **对角线步长 4(N+1) 不是 4N**；终点 4N(N+1) 不是 4N²。
8. **rep; ret / repz retq = 普通 ret**。
9. **机器不做边界检查**：`a[k]` 就是"基址+4k"，C 层面越界是未定义行为——缓冲区溢出（3.46）的根源。
10. **栈帧 16 字节对齐**：call 前 %rsp ≡ 0 (mod 16)；`subq` 的大小含对齐填充，差额别当成存了数据。
11. **%rsp 只认 call/ret**（±8），其余指令不动栈；`*%rsp` = 最近未弹的返回地址。
12. **callee-saved 共 6 个**：跨调用存值"寄存器→用满 6 个→上栈"，别指望 caller-saved。
