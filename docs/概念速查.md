## 跨章易混概念辨析 ⚠️

| 概念 A | 概念 B | 区别 |
|---|---|---|
| **并发** | **并行** | 并发是宏观同时（可交错），并行是真正同时（多核） |
| **局部符号** | **局部变量** | 局部符号是 static 的（在符号表）；局部变量在栈上（不在符号表） |
| **`.data`** | **`.bss`** | 前者已初始化占文件空间；后者未初始化**不占**文件空间 |
| **强符号** | **弱符号** | 强 = 函数/已初始化；弱 = 未初始化全局变量 |
| **静态库** | **动态库** | 前者链接时复制进可执行文件；后者运行时加载、共享 |
| **中断** | **陷阱** | 中断异步、来自外部；陷阱同步、有意（系统调用） |
| **故障** | **终止** | 故障可恢复、可能重执行；终止不可恢复、不返回 |
| **fork** | **execve** | fork 复制进程；execve 用新程序覆盖当前进程 |
| **僵尸** | **孤儿** | 僵尸是子死父未收；孤儿是父死子被 init 收养 |
| **待处理** | **阻塞** | 待处理是已发未收；阻塞是暂时不接收（信号仍在） |
| **TLB** | **Cache** | TLB 缓存**页表项**；Cache 缓存**数据/指令** |
| **内部碎片** | **外部碎片** | 内部在已分配块内；外部是空闲块不连续 |
| **写回** | **写直通** | 写回延迟写下层（需脏位）；写直通立即写 |
| **写分配** | **非写分配** | 写缺失时是否先载入块 |
| **首次适配** | **最佳适配** | 首次找第一个够大的（快）；最佳找最接近的（利用率高但慢） |
| **逻辑移位** | **算术移位** | 逻辑补 0；算术补符号位 |
| **物理寻址** | **虚拟寻址** | 直接发物理地址 vs 经 MMU 翻译 |
| **PC 相对重定位** | **绝对重定位** | R_X86_64_PC32（可 PIC）vs R_X86_64_32 |
| **流水线** | **超标量** | 流水线重叠执行；超标量每周期发射多条 |
| **延迟** | **吞吐量** | 单任务耗时 vs 单位时间任务数 |
| **CPE** | **CPI** | 每**元素**周期数 vs 每**指令**周期数 |
