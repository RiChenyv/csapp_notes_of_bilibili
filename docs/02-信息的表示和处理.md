# 第 2 章 信息的表示和处理

> 对应课程：短系列 2-1 ~ 2-4（8P）｜直播版 P1 ~ P4
> 本章是**数据表示**的地基：位、整数（补码）、浮点。考研/408 与 Data Lab 的核心。

---

## 2.1 信息的存储

### 2.1.1 基本单位

| 单位 | 说明 |
|---|---|
| 位（bit） | 0/1，最小单位 |
| 字节（byte） | 8 位，**最小的可寻址单位** |
| 字（word） | 字长，机器字长 64 位时 1 word = 8 字节 |
| 虚拟地址 | 用字来编码，指向某个字节 |

**十六进制（Hex）**：每 4 位二进制 = 1 个十六进制位，是二进制的缩写。
- `0x` 前缀；`A~F` 表示 10~15
- 换算：二进制 4 位一组 → 十六进制一位，反之亦然。

⚠️ **字长与地址**
- 32 位机：指针 4 字节，虚拟地址空间 $2^{32}$ 字节 = 4 GB
- 64 位机：指针 8 字节，虚拟地址空间 $2^{64}$（实际只用了 48 位左右，即 48 位地址 = 256 TB）

### 2.1.2 字节顺序（Endianness）⚠️

多字节数据在内存中如何排列：

| 类型 | 低地址存放 | 例：`0x01234567`（地址 0x100 起） |
|---|---|---|
| **小端（Little Endian）** | 最低有效字节 | `100:67 101:45 102:23 103:01`（x86/ARM） |
| **大端（Big Endian）** | 最高有效字节 | `100:01 101:23 102:45 103:67`（网络字节序） |

💡 **记忆**："小端 = 低位在低地址"。判断技巧：写内存地址从左到右递增，小端序列与书写顺序"反过来"。

📌 **常见考点**：字节序影响网络通信、文件格式、`union` 判端、`memcpy` 结果；**网络字节序是大端**。

### 2.1.3 位运算与逻辑运算

| 位运算 | 符号 | 说明 |
|---|---|---|
| 与 | `&` | 全 1 才 1 |
| 或 | `\|` | 有 1 则 1 |
| 非 | `~` | 按位取反 |
| 异或 | `^` | 相同为 0，不同为 1 |

**逻辑运算**（`&&`、`||`、`!`）：结果为 0/1，且**短路求值**（短路：`a && b` 中 a 为假则不判 b）。

⚠️ **掩码技巧**
- `x & 0xFF`：取最低字节
- `x ^ y ^ y = x`：异或的自反性（用于交换、找唯一出现奇数次的数）
- `x & (x-1)`：清除最低位的 1
- `x & -x`：取出最低位的 1（`-x` = 取反加一）

**移位**（⚠️ 高频）
- **左移** `x << k`：低位补 0，等价乘 $2^k$
- **右移**：
  - **逻辑右移** `>>`（对无符号数）：高位补 0
  - **算术右移**（对有符号数）：高位补**符号位**，等价于**向下取整**的除法（负数时与 C 的向零舍入不同）

📌 **易错**：C 语言中移位量 $k$ 必须满足 $0 \le k < w$，否则是**未定义行为**。

## 2.2 整数的表示

### 2.2.1 无符号编码（B2U）

对位向量 $x = [x_{w-1}, \ldots, x_0]$：

$$
\mathrm{B2U}_w(x) = \sum_{i=0}^{w-1} x_i \cdot 2^i \qquad \text{范围 } [0, 2^w - 1]
$$

### 2.2.2 补码编码（B2T）⚠️⚠️

$$
\mathrm{B2T}_w(x) = -x_{w-1} \cdot 2^{w-1} + \sum_{i=0}^{w-2} x_i \cdot 2^i
$$
- 最高位是**符号位**，权重为 $-2^{w-1}$
- 范围：**不对称**，$[-2^{w-1}, 2^{w-1} - 1]$
  - 8 位：$[-128, 127]$；32 位：$[-2147483648, 2147483647]$
  - ⚠️ $\mathrm{TMin}$ 没有对应的正数！$-\mathrm{TMin} = \mathrm{TMin}$（溢出）

**原码 / 反码 / 补码**（408 常考）
| 编码 | 负数规则 | 问题 |
|---|---|---|
| 原码 | 符号位 1 + 绝对值 | 有 $\pm 0$，加减要判符号 |
| 反码 | 原码除符号位取反 | 有 $\pm 0$ |
| **补码** | 反码 + 1（等价 $2^w - \lvert x \rvert$） | **0 唯一，加减统一**，现代通用 |

💡 补码由来：$-x$ 与 $x$ 相加需为 0（模 $2^w$），故 $-x = 2^w - x$。

### 2.2.3 有符号 ↔ 无符号转换 ⚠️

$$
\mathrm{T2U}_w(x) = x + x_{w-1} \cdot 2^w \\
\mathrm{U2T}_w(u) = u - u_{w-1} \cdot 2^w
$$
- 位模式不变，只是**重新解释**。
- 负数转无符号：加 $2^w$；无符号 $\ge 2^{w-1}$ 转有符号：减 $2^w$。

📌 **C 语言的坑**：有符号与无符号混合运算，**有符号会被隐式转为无符号**！
```c
if (-1 < 0U)   // 恒假！-1 转成 UMax = 4294967295
```
典型 bug：`for (unsigned i = n-1; i >= 0; i--)` 死循环。

### 2.2.4 扩展与截断

| 操作 | 规则 |
|---|---|
| **零扩展**（无符号） | 高位补 0 |
| **符号扩展**（有符号） | 高位补符号位 |
| **截断** | 直接丢弃高位，结果为原值 $\bmod 2^k$ |

⚠️ 转换顺序：C 中先做**扩展/截断**到相同位数，再做有符号/无符号解释。

## 2.3 整数的运算

### 2.3.1 无符号加法与溢出

$$
s = (x + y) \bmod 2^w
$$
- **溢出判定**：结果 $s < x$（或 $s < y$）即发生溢出，真实和 $= s + 2^w$。
- 无符号加法构成**模 $2^w$ 的加法群**。

### 2.3.2 补码加法与溢出 ⚠️

同样按位加、丢弃进位，但有符号解释：
- **正溢出**：正 + 正 → 负（真实和 $\ge 2^{w-1}$）
- **负溢出**：负 + 负 → 正（真实和 < $-2^{w-1}$）

**判定（408 高频）**：设 $s = x + y$（补码加法结果）
- 正数加正数得负数 → 正溢出
- 负数加负数得正数 → 负溢出
- 也可用**双符号位**（变形补码）：`00` 正常、`01` 正溢出、`10` 负溢出。

### 2.3.3 补码取负

```
-x = ~x + 1   （位级：取反加一）
```
- $\mathrm{TMin}$ 取负仍是 $\mathrm{TMin}$（溢出）。
- 判定 $x < 0$ 可用 `x >> (w-1)`。

### 2.3.4 乘法

- 无符号：$(x \cdot y) \bmod 2^w$
- 补码：**位级与无符号乘法完全相同**（低 w 位一致），只是解释不同。
- 溢出：结果截断到 w 位。

**乘常数优化**：编译器把 `x * C` 转为**移位 + 加减**。
- `x * 2^k` ⇔ `x << k`
- `x * 5` ⇔ `(x << 2) + x`
- `x * 7` ⇔ `(x << 3) - x`
- 例：`x * 14` = `(x<<3) + (x<<2) + (x<<1)` 或 `(x<<4) - (x<<1)`

### 2.3.5 除以 2 的幂 ⚠️

- **无符号**：`x >> k`（逻辑右移），**向下取整**。
- **有符号**：算术右移是**向下取整**，而 C 的除法要求**向零舍入**，二者对负数不同！
  - 修正偏置：`(x + (1 << k) - 1) >> k`，即 `(x < 0 ? x + (1<<k)-1 : x) >> k`
  - 例：`-7 / 4`，C 语言得 `-1`（向零），但 `-7 >> 2 = -2`（向下）。

📌 **结论**：编译器只有在**能确定非负**或**除数是 2 的幂**时才用移位替代除法。

## 2.4 浮点数（IEEE 754）⚠️⚠️

### 2.4.1 表示格式

$$
V = (-1)^s \times M \times 2^E
$$
| 精度 | 总位 | 符号 s | 阶码 e | 尾数 f | Bias |
|---|---|---|---|---|---|
| 单精度 float | 32 | 1 | **8** | **23** | 127 |
| 双精度 double | 64 | 1 | **11** | **52** | 1023 |

- $\mathrm{Bias} = 2^{k-1} - 1$（k 为阶码位数）

### 2.4.2 三类情况 ⚠️

| 类别 | 阶码 e | 尾数 f | 含义 |
|---|---|---|---|
| **规格化** | $0 < e < 255$ | 任意 | $M = 1.f$（隐含前导 1），$E = e - \mathrm{Bias}$ |
| **非规格化** | $e = 0$ | 任意 | $M = 0.f$，$E = 1 - \mathrm{Bias}$（用于表示 0 和接近 0 的数） |
| **特殊值** | $e = 255$ | $f = 0$ | $\pm\infty$（溢出） |
| **特殊值** | $e = 255$ | $f \ne 0$ | `NaN`（非数，如 $0/0$、$\sqrt{-1}$） |

💡 **平滑过渡**：非规格化数与规格化数的切换是无缝的（$e=0$ 时 $E=1-\mathrm{Bias}$ 而非 $-\mathrm{Bias}$）。

**关键数值（单精度）**
- `0x00000000` = `+0.0`；`0x80000000` = `-0.0`（⚠️ 两者相等但位模式不同）
- 最大规格化数、最小正规格化数 $2^{-126}$、最小正非规格化数 $2^{-149}$
- $+\infty$ = `0x7F800000`，`NaN` = `0x7FC00000`

### 2.4.3 舍入（Rounding）⚠️

IEEE 754 默认 **向偶数舍入（Round-to-Even）**：
- 恰好在两数中间时，向**最低有效位为偶数**的方向舍入。
- 例：$1.5 \to 2$，$2.5 \to 2$（不是 3），$0.5 \to 0$。
- 四种模式：向偶数、向零、向下、向上。

📌 为何用向偶数：避免统计偏差，是最"公平"的默认。

### 2.4.4 浮点运算与性质

- 浮点加法**不满足结合律**：$(a+b)+c \ne a+(b+c)$（舍入误差）
- 浮点乘法也不满足结合律、分配律
- `Inf - Inf = NaN`，`0/0 = NaN`
- 溢出 → $\pm\infty$

### 2.4.5 类型转换（⚠️ 高频）

int / float / double 互转时，**位模式会变**：

| 转换 | 规则 |
|---|---|
| int → float | 可能舍入（有效位数不够），可能溢出为 Inf（不会） |
| int → double | 精确（double 53 位有效数 > int 32 位） |
| float → double | 精确 |
| double → float | 可能舍入/溢出 |
| float/double → int | **向零截断**；超出范围是**未定义行为** |
| int/float → unsigned | 先转有符号规则，再套 unsigned（负数会绕回） |

📌 例：`(int)1e20` 未定义；`(float)2147483647` 舍入为 `2147483648.0f`。

## 本章速记

- 补码：`-x = ~x + 1`；范围 $[-2^{w-1}, 2^{w-1}-1]$；$\mathrm{TMin}$ 无相反数
- 有符号↔无符号：位不变，$\pm 2^w$ 重新解释
- 乘除 2 的幂：左移/右移；**负数除法要加偏置**
- IEEE 754：$V = (-1)^s \times M \times 2^E$；单精度 8+23，双精度 11+52
- 默认**向偶数舍入**；浮点加法不满足结合律
- 现代机器：**小端**；网络字节序：**大端**
